Does Financial News Sentiment Move the S&P 500?

DATA 498D Capstone Group Project | NLP Lead

Python · NLP · Finance

Tested whether daily financial headlines contain useful information about next-day S&P 500 direction, returns, and long/flat strategy performance.

19,127raw headlines
18,153cleaned headlines
3,506daily observations
51.4%best balanced accuracy
  • Owned dictionary sentiment, VADER, FinBERT scoring, LDA topic features, and sentiment feature comparison.
  • Compared Logistic Regression and XGBoost with time-aware validation, threshold selection, and held-out testing.
  • Reported results cautiously: Logit + FinBERT produced a selected 13.1% test backtest versus 7.0% buy-and-hold, but the signal was weak and regime-dependent.

Predicting Bank Term Deposit Subscription Under Class Imbalance

STAT 474 Machine Learning Final Project

ML · Business Analytics

Built a leakage-aware classification workflow for UCI Bank Marketing data, where only 11.27% of clients subscribed to a term deposit.

41,188observations
11.27%positive class
0.510best F1
0.479best PR-AUC
  • Removed post-call duration to avoid outcome leakage; converted pdays = 999 into a previous-contact indicator.
  • Compared Logistic Regression, LASSO, Naive Bayes, Random Forest, Weighted XGBoost, and PCA + Logistic.
  • Used five-fold cross-validation and out-of-fold threshold tuning to connect model choice with call-cost and subscriber-value tradeoffs.
