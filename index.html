DATA 498D Capstone | NLP Lead

Does Financial News Sentiment Move the S&P 500?

A group capstone project testing whether daily financial headlines contain useful information about next-day S&P 500 direction, returns, and simple long/flat trading performance.

19,127raw headlines
18,153cleaned headlines
3,506daily observations
  • Owned the NLP feature work: dictionary sentiment, VADER, FinBERT scoring, and LDA topic features.
  • Compared sentiment feature sets using time-aware Logistic Regression and XGBoost pipelines.
  • Found weak, unstable, regime-dependent signal: best held-out balanced accuracy was 51.4%.
  • Reported the most promising backtest cautiously: Logit + FinBERT returned 13.1% versus 7.0% buy-and-hold, but depended on threshold and regime choices.

STAT 474 Machine Learning Final Project

Predicting Bank Term Deposit Subscription Under Class Imbalance

A supervised learning project on UCI Bank Marketing data, focused on identifying likely term-deposit subscribers when the positive class is rare.

41,188observations
11.27%positive class
0.510best F1
  • Removed post-call duration to avoid leakage and treated pdays = 999 as a previous-contact indicator.
  • Compared Logistic Regression, LASSO, Naive Bayes, Random Forest, Weighted XGBoost, and PCA + Logistic.
  • Used five-fold cross-validation and out-of-fold threshold tuning before final held-out test evaluation.
  • Connected threshold choice to business value, call cost, false positives, and missed subscribers.
